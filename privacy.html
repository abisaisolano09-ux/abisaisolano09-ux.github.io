Privacy Policy – Ugo Subidas

Last updated: November 10, 2026

Ugo Subidas is a private desktop tool used only by the owner of the YouTube channels it is connected to (including "Ugo Caveman") to upload the owner's own videos and manage those channels.

1. YouTube API Services

Ugo Subidas uses YouTube API Services. By using Ugo Subidas, users agree to be bound by the YouTube Terms of Service. Google Privacy Policy.

2. Information we access and use

With the user's permission (Google OAuth 2.0), Ugo Subidas accesses the authorized YouTube channel only to:

  • upload the user's own video files;
  • set their title, description, tags, category and thumbnail;
  • schedule their publication time;
  • read comments on the user's own videos and post replies or comments as the channel;
  • read the channel name and basic video statistics to confirm the correct channel and see how the videos perform.

It does not collect or display data of other channels outside of the comments on the user's own videos.

3. Information we store

Ugo Subidas does not store any YouTube data on any server. The only information kept is the OAuth authorization token, saved in a file on the user's own computer so the user does not have to sign in every time. No data is sent to the developer or to any third party.

4. Information we share

We do not share, sell, rent or disclose any user information to anyone.

5. Cookies and device information

Ugo Subidas does not use cookies and does not collect device information.

6. Data deletion

  • Delete the token files ("token*.json") from the program folder to remove the stored authorization from the computer immediately.
  • Revoke Ugo Subidas' access to your Google account at any time here: https://security.google.com/settings/security/permissions

After revocation, Ugo Subidas can no longer access the channel. Since no other data is stored, nothing else needs to be deleted.

7. Changes to this policy

Any change will be published on this page with a new "Last updated" date.
